# GHZ-Converter
How to use it: There is 3 blocks in this code
Requirments: Python, numpy, file with data named "Measurements.txt"

Blocks:
1) Quantum circuit block
2) Data input and Matrix reconstruction functions
3) Final part of the function and main program

Requirement to .txt File: 3 numbers in a line without empty lines.

Starting Python code you will have to input a starting state for Quantum Circuit (For example |000>. Also |000> used in the main Research);
The result can be expressed as: Ideal and Physical Hadamard gate Deviation, Resulting matrix & vector.
